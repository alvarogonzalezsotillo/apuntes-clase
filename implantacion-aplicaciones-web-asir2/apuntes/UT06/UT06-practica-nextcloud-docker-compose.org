* Objetivos de la práctica:
:PROPERTIES:
:UNNUMBERED: t
:END:
En esta práctica se espera que el alumno:
- Se familiarice con el uso de docker compose para instalar aplicaciones web
- Instale y configure Nextcloud


* Instalación de Nextcloud (4 puntos)
Modifica del fichero de /docker compose/ de la teoría para que:
- El nombre del /stack/ sea =nextcloud-/tunombre/=
- Las contraseñas de /mysql/ y /nextcloud/ se indicarán en un fichero aparte: =.env=
- No es necesario usar una caché /redis/
- Los datos estarán en directorios con ruta relativa desde el =yml=:
  - Los datos de Nextcloud estarán el directorio =./nextcloud/=
  - Los datos de /mysql/ estarán el el directorio =./db/=  

* Backups de la base de datos (5 puntos)
- Habrá un container /debian/ que tendrá un /cron/ de usuario que cada minuto hará un backup de la base de datos (no de los ficheros de Nextcloud):
  - Modifica el container /debian/ con la opción =post_start=
  - Instala herramientas necesarias con =apt=
  - Usa /crontab -/ para insertar una nueva tarea programada
  - Los backups se grabarán en el directorio =./backups= relativo al fichero =yml= (móntalo como volumen)
  - Los backups tendrán de nombre =YYYY-MM-DD-HH-MM.sql=  

- Nota: no es necesario leer las contraseñas del fichero =.env=
