* Objetivo de la práctica
:PROPERTIES:
:UNNUMBERED: t
:END:
Durante el desarrollo de esta práctica, el alumno:
- localizará una vulnerabilidad para conseguir los /hashes/ de las contraseñas
- Utilizará conocimientos de otros módulos (redes, sistemas operativos) para /crackear/ los hashes

* Máquina vulnerable
:PROPERTIES:
:UNNUMBERED: t
:END:
- El ordenador =debian13-tiny.local= está mal configurado
- Por error, el disco principal (donde está el /filesystem/ raíz y el directorio =/etc/=), es legible por todos los usuarios
- Se conoce que el usuario =alumno=  puede hacer /login/ mediante SSH, con la contraseña =alumno= 

* Consigue los /hashes/ de las contraseñas (4.9995 puntos)
Utiliza conocimientos de otros módulos para conseguir los /hashes/ de las contraseñas
- ¿En qué fichero están? (Módulo SOM)
- ¿Cómo puedo montar el disco? (Módulo SOM)
- ¿Cómo puedo traer el disco a una máquina donde sea administrador? (Módulos SOM, PAR)
