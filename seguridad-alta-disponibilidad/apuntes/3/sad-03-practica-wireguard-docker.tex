\section{Objetivo de la práctica}
\label{sec:org0000000}

Tras la realización de esta práctica, el alumno será capaz de:

\begin{itemize}
\item Comprender el concepto de \emph{seguridad perimetral} y aislamiento de servicios.
\item Crear y gestionar redes puente con \emph{Docker}.
\item Desplegar un servidor \emph{Apache} aislado, sin exposición directa al host.
\item Desplegar un servidor \emph{VPN} con \href{https://github.com/wg-easy/wg-easy}{wg-easy} para dar acceso remoto seguro.
\item Verificar que un servicio solo es accesible a través del túnel \emph{WireGuard}, quedando inaccesible desde el exterior sin VPN.
\end{itemize}

Está disponible la \href{https://alvarogonzalezsotillo.github.io/apuntes-clase/seguridad-alta-disponibilidad/apuntes/3/sad-03-practica-wg-easy-apache-solo-vpn.pdf}{última versión de esta práctica en este enlace}.
\section{Descripción del problema}
\label{sec:org0000003}

Se desea que un servidor web \emph{Apache} solo accesible mediante una VPN.

Únicamente los clientes que se conecten al servidor \emph{VPN} levantado con \emph{wg-easy} podrán acceder a dicho servidor \emph{Apache}.

Se expondrá al host el túnel \emph{WireGuard} (UDP 51820) y, la interfaz web de gestión de \emph{wg-easy} (TCP 51821).

El puerto 51820 será accesible desde el exterior. El puerto 51821 será solo accesible al host.

Se instalará Portainer en el host, para poder inspeccionar fácilmente los \emph{containers}.

\section{Requisitos}
\label{sec:org0000006}

\begin{itemize}
\item Equipo host con \emph{Docker} instalado, para los servidores (máquina virtual)
\begin{itemize}
\item Con interfaz gráfica para acceder a Portainer
\item Permisos para crear redes, contenedores y modificar \texttt{sysctl} (root)
\end{itemize}
\item Equipo con interfaz gráfica donde instalar el cliente de VPN (máquina virtual).
\begin{itemize}
\item Windows, o bien
\item Linux con KDE (Gnome debería servir, pero no está probado por el profesor)
\end{itemize}
\item Conexión a Internet para descargar las imágenes
\begin{itemize}
\item \texttt{docker.io/weejewel/wg-easy:latest}
\item \texttt{docker.io/library/httpd:2.4}.
\end{itemize}
\end{itemize}
\section{Pasos a seguir}
\label{sec:org0000009}

Orientativamente, puedes seguir estos pasos:
\begin{enumerate}
\item \textbf{Docker.} La forma más fácil es con el \href{https://docs.docker.com/engine/install/ubuntu/\#install-using-the-convenience-script}{\emph{script} de conveniencia} en una máquina virtual linux.
\item \textbf{Portainer.} (opcional) \href{https://docs.portainer.io/start/install-ce/server/docker/linux}{Se utilizará la \emph{comunity edition}}. Puede ayudar a crear containers y a inspeccionar el estado de Docker.
\item \textbf{Creación de red interna.} \href{https://docs.docker.com/reference/cli/docker/network/create/}{Crea la red interna} \emph{Docker} donde conectar el servidor web y el servidor VPN.
\item \textbf{Despliegue de Apache.} Despliega un contenedor con \href{https://hub.docker.com/\_/httpd}{\texttt{httpd:2.4}}.
\begin{itemize}
\item Conéctalo \href{https://stackoverflow.com/a/35359185}{únicamente a la red interna y con una ip} concreta.
\item Crea una página \texttt{index.html} personalizada en un \href{https://hub.docker.com/\_/httpd\#without-a-dockerfile}{volumen conectado al directorio raiz de Apache}.
\end{itemize}
\item \textbf{Despliegue de wg-easy.} Despliega el \href{https://hub.docker.com/r/weejewel/wg-easy}{contenedor \texttt{wg-easy}}
\begin{itemize}
\item Conecta el puerto 51820 UDP al host
\item Conecta el puerto 51821 TCP al host, \href{https://stackoverflow.com/a/22100687}{pero solo accesible desde el propio host}
\item Conéctalo también a la red interna.
\item \href{https://hub.docker.com/r/weejewel/wg-easy\#2-run-wireguard-easy}{Habilita el reenvío IP y configura los parámetros necesarios} para que los clientes VPN puedan alcanzar la subred interna.
\item Haz un volumen en \texttt{/etc/wireguard} dentro del container, o los usuarios que crees podrían perderse.
\end{itemize}
\item \textbf{Configuración del cliente VPN.} Desde el panel web de \emph{wg-easy} (puerto 51821, con un navegador), crea un cliente \emph{WireGuard}, descarga su configuración o código QR y conéctalo.
\item \textbf{Comprobación del aislamiento.} Comprueba que sin estar conectado a la VPN no se accede a \emph{Apache} y, con la VPN activa, sí se accede mediante la IP del contenedor \emph{Apache} desde el cliente VPN.
\end{enumerate}
